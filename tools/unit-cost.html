How it is calculated. API cost = input tokens ÷ 1,000,000 × input price + output tokens ÷ 1,000,000 × output price. Homelab cost = hours × hardware $/h + (watts × hours ÷ 1000) × $/kWh. When deriving duration, hours = (input tokens ÷ prompt speed + output tokens ÷ generation speed) ÷ 3600, assuming one job runs at a time. Default values are editable examples, not quotes for any provider or device. Output quality, setup time, and idle power are not included.
